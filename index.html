Articles: a / an, the, zero (—)

Артиклі. Артикль показує, чи йдеться про щось загальне або нове, чи про щось конкретне й відоме.

A / AN

Невизначений артикль. Лише зі злічуваними іменниками в однині; a перед приголосним звуком, an перед голосним.

  • First mention: a door, a meter, a matchПредмет чи особа згадуються вперше.
  • Profession: he is an employee, a meter readerПрофесія або ким є людина.
  • Fixed expressions: as a matter of fact; an explosion, an envelopeСталі вирази. Перед голосним звуком вживаємо an.

THE

Визначений артикль. З однина, множина та незлічуваними іменниками.

  • Mentioned before: I saw a dog. The dog was big.Про предмет чи особу вже йшла мова.
  • Clear from context: the gaspipe, the doorЗ контексту зрозуміло, про що йдеться.
  • Ordinals, superlatives: the last house, the first day, the best friendПорядкові числівники, вищий і найвищий ступінь.
  • Unique: the owner of the house, the policeУнікальні у цій ситуації слова.
  • the light of…, the back of…, the time of…Конструкції з of.

Zero article (—)

Нульовий артикль. Артикль не потрібен.

  • General plural: Meter readers usually wear peaked caps.Множина для узагальнення.
  • Possessive with a name: Mr Smith’s houseПрисвійний відмінок із власною назвою.
  • Abstract nouns, fixed expressions: in surpriseДеякі абстрактні іменники та сталі вирази.

SHOULD / SHOULDN’T

Should означає «слід, варто», shouldn’t означає «не слід, не варто». Однакова форма для всіх осіб.

Use

Використання.

  • AdviceExampleYou should see a doctor.Порада.
  • Advice not to do somethingExampleYou shouldn’t eat so much sugar.Порада не робити щось.
  • What is right or wrongExampleWe should help our friends.Що правильно або доцільно.
  • Asking for adviceExampleShould I take an umbrella?Прохання про пораду.

Form

Форма. Після should завжди інфінітив без to, без закінчення -s.

Positive (+)
Formulasubject + should + verb
ExampleShe should study more.
Ствердження.
Negative (−)
Formulasubject + shouldn’t + verb
ExampleShe shouldn’t be late.
Заперечення.
Question (?)
FormulaShould + subject + verb?
ExampleShould she call him?
Запитання.
Always the base verb: no to, no -s. He should go. (not: He should goes)

Conditional Sentences (III): Unreal Condition

Умовні речення III типу. Нереальна умова.

Use: an unreal situation in the past. It did not happen, so we only imagine the result. Often we express regret or criticism.

Використання. Нереальна ситуація в минулому: це не відбулося, тому результат лише уявний. Часто виражає жаль або докір.

Form: If + Past Perfect (had + V3), would / could / might + have + V3.
If I had studied, I would have passed the exam.

Форма. If + Past Perfect, would / could / might + have + V3.

Negative: If she hadn’t left early, she wouldn’t have missed the train.

Заперечення: hadn’t і wouldn’t have + V3.

Order: either part can go first. Comma only when the if-clause is first: I would have passed if I had studied.

Порядок. Кома ставиться, лише коли речення починається з if. Реальний факт: I didn’t study, so I didn’t pass.

Remember: never use would in the if-clause. Type 1: If + Present Simple, will + V (real). Type 2: If + Past Simple, would + V (unreal present).

Не вживаємо would після if. I тип: If + Present Simple, will + V. II тип: If + Past Simple, would + V.
